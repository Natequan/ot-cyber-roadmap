# Nocturne — Mechatronics → OT / Embedded Security

A public learning roadmap, technical portfolio and evidence system for a mechatronics engineering career focused on **industrial automation, embedded systems, networking and OT / ICS cybersecurity**.

- **Professional portfolio:** https://natequan.github.io/ot-cyber-roadmap/portfolio.html

## What this repository contains

Nocturne combines two related goals:

1. **Structured learning** — guided weekly modules for networking, Python, Linux, cybersecurity, CCNA-level practice and OT / ICS security.
2. **Professional evidence** — real university labs and engineering projects converted into recruiter-readable case studies with architecture, code, photos, troubleshooting, results and limitations.

## Current documented work

### Industrial Modbus RTU Integration — Schneider M221 ↔ PowerLogic PM5110
Industrial serial communication over RS-485 with PLC Ladder communication logic, Modbus register mapping, manufacturer documentation lookup and troubleshooting.

### Raspberry Pi Eye-Tracking Writing System
Raspberry Pi 4B + Python + OpenCV computer-vision pipeline with UDP communication, coordinate smoothing and OLED feedback.

### Low-Cost Automated PCB Prototyping Cell
Arduino-controlled CNC plotter combined with PCB etching, Fusion 360, Proteus, 3D printing, laser processes and ShopBot fabrication.

### IoT Irrigation & AC Pump Control
Cyber-physical irrigation prototype using capacitive moisture sensing, embedded control, IoT monitoring and an optoisolated TRIAC-based AC power stage.

### Networking laboratory series
Hands-on evidence covering structured cabling, fiber, Cisco CLI access, MAC tables, ARP, IPv4 addressing, routing, DHCP server/relay/client behavior and connectivity verification.

## Engineering direction

Primary direction:

**Mechatronics → Industrial Automation → Networking → OT / Embedded Security**

The goal is not to collect certificates in isolation. Each learning block should produce evidence: a lab, script, capture, diagram, configuration, report or project improvement.

## Portfolio integrity

Project claims are based on real artifacts such as reports, code, photos, CAD files or laboratory records. Team and individual contributions are described separately, and unsupported performance claims are intentionally avoided.
