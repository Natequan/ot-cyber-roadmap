# AI maintenance contract

This repository is structured so ChatGPT can maintain the roadmap and portfolio through the connected GitHub account.

## Before every write

1. Read the current repository state and the file being modified.
2. Do not invent completed labs, metrics, screenshots, hardware models, test results or certifications.
3. Preserve user-authored technical details unless a correction is explicitly requested.
4. Never commit credentials, API tokens, school login data, private production addresses or secrets.
5. Keep cybersecurity work scoped to authorized labs and defensive/educational use.

## Weekly progress sync

- Store weekly reports under `reports/`.
- If a report contains real project progress, update the matching `projects/*.md` file.
- Modify `data/roadmap.js` only when the plan itself changes.
- Keep README-facing claims evidence-based.

## Mature project standard

A strong project should include objective, architecture, hardware/software, communications, implementation, test method, results/evidence, troubleshooting, security analysis, limitations and next iteration.

## Career positioning

Keep the portfolio coherent around:

> Mechatronics → Industrial Automation → OT / Embedded / Product Security
