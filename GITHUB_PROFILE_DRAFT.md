## Selected engineering work

### Industrial Modbus RTU Integration — Schneider M221 ↔ PowerLogic PM5110
Configured and validated Modbus RTU communication over RS-485, including serial settings, PLC Ladder communication logic, manufacturer register-table lookup, PLC memory mapping and troubleshooting an addressing offset.

### Raspberry Pi Eye-Tracking Writing System
Implemented the Raspberry Pi 4B Python software for a gaze-controlled writing prototype using OpenCV pupil detection, coordinate smoothing, UDP communication, threading and OLED feedback.

### Low-Cost Automated PCB Prototyping Cell
Contributed across a hybrid digital-manufacturing workflow combining an Arduino-based CNC plotter, PCB tracing and etching, Fusion 360, Proteus, PETG 3D printing, laser processes and ShopBot fabrication.

### IoT Irrigation & AC Pump Control
Built a cyber-physical irrigation prototype around capacitive soil-moisture sensing, embedded control, IoT monitoring and an optoisolated TRIAC-based AC pump power stage.
