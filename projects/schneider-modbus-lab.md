# Schneider Modbus Industrial Communication Lab

## Status

Planned / active university lab. Fill factual hardware and communication details only after verification on the real setup.

## Goal

Build a reproducible industrial communications project demonstrating Schneider PLC configuration, Modbus RTU / RS-485 fundamentals, register mapping, PC-based monitoring or scripting, and safe defensive OT-security analysis.

## Evidence to collect

- [ ] Exact PLC model
- [ ] Exact HMI / RS-485 device model
- [ ] Software/version used
- [ ] Topology diagram
- [ ] RS-485 A/B wiring reference
- [ ] Baud rate
- [ ] Parity
- [ ] Stop bits
- [ ] Slave/server address
- [ ] Register table
- [ ] Working communication evidence
- [ ] Python read-only client
- [ ] Error handling / logging
- [ ] Security architecture notes

## Security extension

After normal operation is understood and documented, threat-model the lab, map relevant concepts to MITRE ATT&CK for ICS, and compare the architecture against NIST SP 800-82 recommendations.
